Low-Poly Coffee Mug

📦 Description
A simple 3D coffee mug in low-poly style.
Perfect for games, mobile apps, low-poly renders, or real-time scenes.

---

🗂️ Included Files
- "Mug_low-poly.blend" – Blender source file
- "Mug_low-poly.fbx" – Exported FBX version

Formats: ".blend", ".fbx"
Scale: actual size

---

⚙️ Instructions
-Open the ".blend" file in Blender for full editing.
-Or import the ".fbx" into Unity, Unreal, Godot, etc.

🎨 Want a different color?
In Blender, select the mug, go to the Material Properties tab, and change the Base Color to whatever you like.
In a game engine, simply assign a new material with the color of your choice.
