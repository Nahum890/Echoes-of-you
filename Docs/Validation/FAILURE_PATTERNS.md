# FAILURE_PATTERNS.md — Catalog of Known Error Codes & Failure Patterns
## Spec ID: SPEC-303
## Version: 3.0 (AI-Executable)

---

### 1. PURPOSE
Defines the canonical catalog of error codes (`FAIL-xxx`), root causes, detection algorithms, and corrective actions for validation failures in *Echoes of You 2.0*.

### 2. SCOPE
Applies to automated test suites, `LevelValidator.cs`, `LevelScorecard.cs`, and AI execution loops.

### 3. AUTHORITY
Nivel 4 (Validación y QA). Subordinate to `SOURCE_OF_TRUTH.md` (`SPEC-000`) and `LEVEL_VALIDATOR.md` (`SPEC-301`).

### 4. DEFINITIONS
- `FAIL Code`: Unique error identifier (`FAIL-category-number`) raised by `LevelValidator.cs` upon rule violation.
- `Corrective Action`: Mandatory programmatic fix required to resolve the failure.

### 7. RULES

- `[RULE-FAL-001]`: **Zero-Error Build Gate**: No scene may be saved or exported if any active `FAIL-xxx` code is raised during Pass 6 of the build pipeline.

### 8. ALGORITHMS

#### Table 8.1: Master Catalog of FAIL Error Codes

| Error Code | Category | Root Cause Violation | Detection Routine | Mandatory Corrective Action |
|---|---|---|---|---|
| `FAIL-ARC-01` | Architecture | Corridor $> 18.0\text{m}$ without landmark | `LevelValidator.ValidateCorridors()` | Insert wall break or landmark prop |
| `FAIL-ARC-02` | Architecture | Interactive element at room center | `LevelValidator.ValidateInteractives()` | Offset element $\ge 1.5\text{m}$ toward wall |
| `FAIL-NAV-01` | Navigation | NavMesh clearance $< 1.2\text{m}$ | `LevelValidator.ValidateNavMesh()` | Space props to restore $1.2\text{m}$ gap |
| `FAIL-CAM-01` | Camera | Dual camera controllers in LateUpdate | `LevelValidator.ValidateCameras()` | Disable legacy `ThirdPersonCamera.cs` |
| `FAIL-CAM-02` | Camera | Unbalanced TargetGroup weights | `LevelValidator.ValidateTargetGroups()` | Set Echo and Player weight $= 1.0$ |
| `FAIL-CAM-03` | Camera | Target line-of-sight occluded $> 0.3\text{s}$ | `LevelValidator.ValidateOcclusion()` | Attach `CinemachineCollider` component |
| `FAIL-PUZ-01` | Puzzle | Solvability without Echo (Button Test) | `LevelValidator.ValidatePuzzleEcho()` | Wire timing or EchoOnly requirement |
| `FAIL-PUZ-02` | Puzzle | Unwired pressure plate to door | `LevelValidator.ValidateWires()` | Attach `PuzzleWire.cs` component |
| `FAIL-LGT-01` | Lighting | Light cap $> 48$ active lights | `LevelValidator.ValidateLights()` | Remove excess light components |
| `FAIL-LGT-02` | Lighting | Dynamic light using Soft Shadows | `LevelValidator.ValidateShadows()` | Set shadow type to `Hard Shadows` |
| `FAIL-ENV-01` | Narrative | Amber `#FFBF00` applied to generic prop | `LevelValidator.ValidateNarrative()` | Restore default material token |
| `FAIL-ENV-02` | Narrative | Level missing key amber narrative item | `LevelValidator.ValidateNarrative()` | Instanciate assigned amber prop |
| `FAIL-PHI-01` | Philosophy | Locomotion speed outside $2.8-4.5\text{m/s}$ | `LevelValidator.ValidatePlayer()` | Reset walk/run speed in script |
| `FAIL-PHI-02` | Philosophy | Text canvas UI rendered in gameplay | `LevelValidator.ValidateUI()` | Delete text label element |

### 9. CONSTRAINTS
- `[CONS-FAL-001]`: Prohibido suppressing `FAIL-xxx` codes without resolving the underlying root cause.

### 10. VALIDATION
- `[VAL-FAL-001]`: `LevelValidator.cs` asserts zero `FAIL` codes present in final build pass.
