# LEVEL_SCORECARD.md — Automated Level Evaluation Rubric
## Spec ID: SPEC-302
## Version: 3.0 (AI-Executable)

---

### 1. PURPOSE
Establishes the quantitative /100 scoring rubric and automated evaluation criteria for levels generated by AI agents in *Echoes of You 2.0*. Defines objective metrics replacing subjective evaluation terms.

### 2. SCOPE
Applies to evaluation reports generated by `LevelValidator.cs` and `LevelRuntimeController.cs`.

### 3. AUTHORITY
Nivel 4 (Validación y QA). Subordinate to `SOURCE_OF_TRUTH.md` (`SPEC-000`) and `LEVEL_VALIDATOR.md` (`SPEC-301`).

### 4. DEFINITIONS
- `Scorecard Grade`: Numerical evaluation out of 100 points ($80/100$ minimum passing score).
- `Objective Proxy`: Quantitative metric evaluating subjective design quality (e.g., player completion time $\le 6\text{min}$ without hint as proxy for puzzle clarity).

- Scorecard report `/100` logged by `LevelValidator.cs`.

### 7. RULES

- `[RULE-SCR-001]`: **Passing Threshold**: A level MUST achieve a total scorecard grade $S_{total} \ge 80/100$ and zero active `FAIL-xxx` errors to pass QA verification.
- `[RULE-SCR-002]`: **Deduction Schedule**: Points are deducted automatically based on quantitative criteria in Table 8.1.

### 8. ALGORITHMS

#### Table 8.1: Quantitative Evaluation Category Weights & Deduction Rules

| Category Name | Max Weight | Evaluation Proxy Metric | Deduction Trigger |
|---|---|---|---|
| **Architecture & Metrics** | 25 Pts | Room height, door clearance, wall thickness | $-5$ per non-standard room height; $-10$ per door clearance $< 2.4\text{m}$ |
| **Echo & Puzzle Logic** | 30 Pts | Echo Button Test, signal wiring, timing floor | $-15$ if solvable without Echo; $-10$ per unwired signal wire; $-10$ if timing $< 0.4\text{s}$ |
| **Lighting & URP** | 15 Pts | Light count cap $\le 48$, fog density match | $-10$ if lights $> 48$; $-5$ if fog color mismatch |
| **Navigation & Clearance**| 15 Pts | NavMesh clearance $R \ge 1.2\text{m}$ | $-10$ per narrow corridor $< 1.2\text{m}$ |
| **Camera & Framing** | 15 Pts | Line-of-sight maintenance, blend duration | $-10$ per occluded camera section $> 0.3\text{s}$; $-5$ per instant cut |

### 9. CONSTRAINTS
- `[CONS-SCR-001]`: Prohibido subjective manual point adjustments without log trace.

### 10. VALIDATION
- `[VAL-SCR-001]`: `LevelValidator.cs` sums category scores and asserts $S_{total} \ge 80$.
