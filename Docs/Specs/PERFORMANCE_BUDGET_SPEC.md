# PERFORMANCE_BUDGET_SPEC.md — Hardware Budgets & Performance Specifications
## Spec ID: SPEC-121
## Version: 4.0 (AI-Executable)

---

### 1. PURPOSE
Defines hard quantitative performance budgets for target platform framerate, frame timing breakdown, draw call caps, triangle limits, batching, and memory allocation caps for *Echoes of You 2.0*.

### 2. SCOPE
Applies to all 15 playable scenes, asset import pipelines, static mesh batching, and automated profiler validation tools (`EchoesPerformanceValidator.cs`).

### 3. AUTHORITY
Nivel 3 (Especificación Ejecutable). Subordinate to `SOURCE_OF_TRUTH.md` (`SPEC-000`). Replaces `SPEC-207`.

### 4. DEFINITIONS
- `Target Framerate`: $60.0\text{ fps}$ on target PC platform (DirectX 11).
- `Frame Budget`: $16.66\text{ ms}$ total frame execution window.

### 6. OUTPUTS
- Compliance report generated by `EchoesPerformanceValidator.cs`.

### 7. RULES

- `[RULE-PRF-001]`: **Target Framerate & Frame Budget**: Target framerate MUST be $60.0\text{ fps}$ ($16.66\text{ ms}$ total frame budget).
- `[RULE-PRF-002]`: **Geometry & Draw Call Caps**: Max draw calls per scene MUST NOT exceed 120. Max triangle count MUST NOT exceed 85,000. Max static batches MUST NOT exceed 40.
- `[RULE-PRF-003]`: **Memory Allocation Caps**: Max RAM footprint MUST NOT exceed $1.2\text{ GB}$. Max VRAM footprint MUST NOT exceed $512\text{ MB}$. Max audio RAM footprint MUST NOT exceed $64\text{ MB}$. Max texture RAM MUST NOT exceed $256\text{ MB}$.

### 8. ALGORITHMS

#### Algorithm 8.1: Master Performance Budget Schema

```yaml
target_platform: "PC (DirectX 11)"
target_framerate_fps: 60.0
frame_budget_ms: 16.66
per_pass_budgets_ms:
  cpu_game_logic: 4.0
  cpu_physics: 2.0
  cpu_audio: 1.0
  gpu_geometry: 5.0
  gpu_lighting: 3.0
  gpu_post_processing: 1.5
  overhead: 1.16
scene_geometry_limits:
  max_draw_calls: 120
  max_triangles: 85000
  max_batches_static: 40
  max_textures_mb: 256
  max_active_lights: 48   # matches LIGHTING_GRAMMAR [RULE-LGT-002]
memory_limits:
  max_ram_gb: 1.2
  max_vram_mb: 512
  max_audio_mb: 64
validation:
  profiler_assertion_tool: "Assets/Editor/EchoesPerformanceValidator.cs"
  fail_code: "FAIL-PERF-01"
```

### 9. CONSTRAINTS
- `[CONS-PRF-001]`: Level build fails automatically if automated profiling exceeds any budget limit by $> 5\%$.

### 10. VALIDATION
- `[VAL-PRF-001]`: `EchoesPerformanceValidator.cs` asserts draw calls $\le 120$ and triangles $\le 85,000$ (`VAL-G-01`).
