# ENVIRONMENT_STORYTELLING.md — Environmental Storytelling & Micro-Scenes
## Spec ID: SPEC-006
## Version: 3.0 (AI-Executable)

---

### 1. PURPOSE
Defines the rules, composition logic, and level-by-level mapping for non-textual environmental storytelling in *Echoes of You 2.0*. Specifies micro-scene assemblies and the strict usage of the `memory-amber` color token (`#FFBF00`).

### 2. SCOPE
Applies to `EchoesPropDecorator.cs`, `NarrativeProp.cs`, `LevelBlueprint` assets, and micro-scene prefabs. Excludes core puzzle mechanics.

### 3. AUTHORITY
Nivel 3 (Especificación Ejecutable). Subordinate to `SOURCE_OF_TRUTH.md` (`SPEC-000`) and `DESIGN_PHILOSOPHY.md` (`SPEC-001`).

### 4. DEFINITIONS
- `Micro-Scene`: A static spatial composition of props conveying a past event without text.
- `Memory-Amber Token`: Material `Mat_Token_memory-amber` (`#FFBF00`) with URP emission intensity $1.2\text{ Lux}$.
- `Narrative Item`: A key object linked to Lyra's memory carrying a `NarrativeProp.cs` component.

### 7. RULES

- `[RULE-ENV-001]`: **Zero Text Expository Rule**: Micro-scenes MUST NOT include readable text notes, audio logs, or dialog overlays.
- `[RULE-ENV-002]`: **Memory-Amber Exclusivity**: The color token `memory-amber` (`#FFBF00`) MUST be applied exclusively to key narrative objects associated with Lyra.
- `[RULE-ENV-003]`: **Micro-Scene Density Cap**: Each level MUST contain between $1$ and $3$ micro-scenes from the standard catalog (Table 8.1). No room may contain $> 2$ micro-scenes.
- `[RULE-ENV-004]`: **Focal Sightline Distance**: A `memory-amber` narrative item MUST be visible in direct line-of-sight across $D_{sightline} \ge 8.0\text{ m}$ from room entrance.

### 9. CONSTRAINTS
- `[CONS-ENV-001]`: Prohibido applying `#FFBF00` amber color to generic environment props (chairs, walls, doors).
- `[CONS-ENV-002]`: Prohibido placing micro-scene props obstructing NavMesh clearance ($R_{clearance} < 1.2\text{m}$).

### 10. VALIDATION
- `[VAL-ENV-001]`: `LevelValidator.cs` asserts exactly 1 key `NarrativeProp.cs` with color `#FFBF00` exists per level.
- `[VAL-ENV-002]`: Inspector asserts zero text canvas UI components exist inside micro-scene prefabs.

### 11. EXAMPLES

#### Example 11.1: Micro-Scene Config in Blueprint YAML

micro_scene_placement:

### 12. FAILURE CASES
- `[FAIL-ENV-001]`: **Amber Token Misuse**: A generic trashcan is colored `#FFBF00`. Result: `LevelValidator` flags `FAIL-ENV-01`.
- `[FAIL-ENV-002]`: **Missing Narrative Item**: Level 03 lacks an amber narrative prop. Result: `FAIL-ENV-02`.
