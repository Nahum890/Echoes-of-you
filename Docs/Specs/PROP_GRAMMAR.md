# PROP_GRAMMAR.md — Prop Placement Grammar & Density Rules
## Spec ID: SPEC-005B
## Version: 1.0 (AI-Executable)

---

### 1. PURPOSE
Defines density rules per room type, forbidden prop combinations, and narrative prop placement rules for *Echoes of You 2.0*. Referenced by `EchoesPropDecorator.cs` and `LevelValidator.cs`.

### 2. SCOPE
Applies to prop decoration routines, prefab assets in `Assets/Prefabs/Props/`, and validation checks. Excludes structural room geometry.

### 3. AUTHORITY
Level 3 (Declarative Specs). Subordinate to `SOURCE_OF_TRUTH.md` (`SPEC-000`) and `PROP_LIBRARY.md` (`SPEC-005`).

### 4. DEFINITIONS
- `Density Rule`: Min/Max prop count per room type per 100m².
- `Forbidden Combo`: Prop pair that must never occupy same room.
- `Narrative Prop`: Prop with `NarrativeProp.cs` component (amber token `#FFBF00`).
- `Placement Grid`: 1.0m snap grid for prop positions.

### 7. RULES
- `[RULE-PRG-001]`: **Density Compliance** — Prop count per room MUST satisfy Table 8.1 density rules for that room's category.
- `[RULE-PRG-002]`: **Forbidden Combos** — Prop pairs in Table 8.2 MUST NOT co-exist in same room module.
- `[RULE-PRG-003]`: **Narrative Prop Isolation** — Exactly 1 narrative prop (`memory-amber` `#FFBF00`) per level. No narrative props in non-designated rooms.
- `[RULE-PRG-004]`: **Grid Snap** — All prop positions MUST snap to 1.0m grid. Rotation MUST snap to 90° increments (except `Arch_Desk`/`Arch_Chair` chaotic: ±15°).
- `[RULE-PRG-005]`: **NavMesh Clearance** — All props MUST maintain $R_{clearance} \ge 1.2\text{m}$ from NavMesh path centerlines.

### 8. ALGORITHMS

#### Table 8.1: Density Rules per Room Category

| Room Category | Min Props / 100m² | Max Props / 100m² | Preferred Categories | Notes |
|---|---|---|---|---|
| `Corridor` | 2 | 6 | Furniture, Decals | Lockers on one wall only |
| `Classroom` | 8 | 18 | Furniture, Narrative | Desks in grid 4x4 or chaotic |
| `Hall` | 4 | 10 | Furniture, Architecture | Central open space required |
| `Stairwell` | 1 | 4 | Architecture, Decals | No props on stairs |
| `Bathroom` | 2 | 8 | Furniture, Decals | Mirrors on walls only |
| `StaffRoom` | 4 | 10 | Furniture, Narrative | Coats on coat rack |
| `Library` | 8 | 20 | Furniture, Architecture | Bookshelves on perimeter |
| `Courtyard` | 3 | 10 | Architecture, Nature | Tree center, benches perimeter |
| `Gym` | 3 | 12 | Furniture, Narrative | Bleachers on one side |
| `Lab` | 6 | 16 | Furniture, Architecture | Beakers on desks |
| `Office` | 4 | 12 | Furniture, Narrative | Files on desk |
| `LiminalClassroom` | 4 | 12 | Furniture, Narrative | Floating desks allowed |
| `MaintenanceCorridor` | 2 | 8 | Architecture, Decals | Pipes on ceiling |
| `EmergencyCorridor` | 1 | 5 | Architecture, Decals | Red lights, barred doors |

#### Table 8.2: Forbidden Prop Combinations (Same Room)

| Prop A | Prop B | Reason |
|---|---|---|
| `Arch_Locker` | `Arch_Locker` (adjacent < 1.2m) | NavMesh block |
| `MesaProfesor` | `PupitreDoble` (same desk spot) | Overlap |
| `Pizarra` | `VentanaMarco` (same wall) | Visual conflict |
| `Estanteria` | `EstanteriaCerrada` (same wall) | Redundant |
| `Prop_Coat` | `AbrigoColgado` (same hook) | Duplicate narrative |
| `Cronometro` | `RelojPared` (same wall) | Time duplication |
| `MochilaLyra` | `Prop_Backpack` (same room) | Single Lyra backpack |

#### Table 8.3: Narrative Prop Placement Rules

| Rule | Specification |
|---|---|
| **Exactly One Per Level** | LevelValidator asserts count == 1 |
| **Room Restriction** | Only in room specified by `ENVIRONMENT_STORYTELLING.md` Table 8.2 |
| **Sightline** | Visible from room entrance at $\ge 8.0\text{m}$ |
| **Height** | Y position $\in [0.5, 1.8]\text{m}$ (player eye level) |
| **Material** | Must use `Mat_Token_memory-amber` (`#FFBF00`) |
| **Emission** | URP Emission intensity $1.2\text{ Lux}$ |

### 9. CONSTRAINTS
- `[CONS-PRG-001]`: Prohibido exceeding max density without `ROOM_LIBRARY.md` override.
- `[CONS-PRG-002]`: Prohibido placing narrative props in corridors unless specified.

### 10. VALIDATION
- `[VAL-PRG-001]`: `LevelValidator.cs` counts props per room and asserts density bounds.
- `[VAL-PRG-002]`: `LevelValidator.cs` scans room for forbidden combos (Table 8.2).
- `[VAL-PRG-003]`: `LevelValidator.cs` asserts exactly 1 narrative prop per level with correct material.
- `[VAL-PRG-004]`: `ExecutableSpecValidator.cs` asserts all prop positions snap to 1.0m grid.

### 11. EXAMPLES
```yaml
prop_placement:
  room_type: "Classroom"
  target_density: 12
  placements:
    - prefab: "Arch_Desk"
      position: [2.0, 0.0, 2.0]
      rotation: [0, 180, 0]
    - prefab: "MochilaLyra"
      position: [4.0, 0.0, 4.0]
      material_token: "Mat_Token_memory-amber"
```

### 12. FAILURE CASES
- `[FAIL-PRG-001]`: **Density Overflow** — Classroom has 25 props (max 18). Result: `FAIL-PRG-01`.
- `[FAIL-PRG-002]`: **Forbidden Combo** — Two `Arch_Locker` adjacent < 1.2m. Result: `FAIL-PRG-02`.
- `[FAIL-PRG-003]`: **Narrative Prop Count** — Level has 0 or 2 amber props. Result: `FAIL-PRG-03`.
