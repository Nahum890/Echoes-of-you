# ENVIRONMENT_GRAMMAR.md

# Gramática visual del entorno

Este documento define qué elementos puede contener cada espacio.

---

# REGLAS

No decorar por decorar.

Todo objeto debe justificar su presencia.

---

# PASILLO

Props mínimos

8

Props máximos

18

Debe contener

Banco.

Ventanas.

Puertas.

Carteles.

Basurero.

Lockers.

Luces.

Nunca

Espacio vacío.

---

# AULA

Debe contener

Pizarrón.

Profesor.

Pupitres.

Ventanas.

Armario.

Basurero.

Libros.

Nunca

Menos de 15 props.

---

# BIBLIOTECA

Debe contener

Estanterías.

Mesas.

Lámparas.

Sillas.

Papeles.

Libros.

Nunca

Lockers.

---

# LABORATORIO

Debe contener

Mesas.

Equipamiento.

Estanterías.

Luces técnicas.

Pizarras.

---

# GIMNASIO

Debe contener

Canastas.

Gradas.

Balones.

Colchonetas.

Puertas metálicas.

---

# PATIO

Debe contener

Árboles.

Bancos.

Macetas.

Faroles.

Carteles.

---

# DENSIDAD

Nunca dejar más de

6 metros

sin un punto de interés visual.

---

# COLOR

Los props deben seguir

70%

Neutros.

20%

Madera.

10%

Color emocional.

Nunca saturar.

---

# SILUETA

Cada espacio necesita

Un elemento dominante.

Un elemento secundario.

Varios elementos pequeños.

Nunca todos del mismo tamaño.
