🚀 Próximos Pasos

1. Aplicar Import Settings en Unity

Abrir Unity → Window → Echoes → Texture Optimizer
→ Tab "📋 Audit" → Escanear Proyecto
→ Tab "⚙️ Optimize" → Dry Run primero
→ Verificar preview → Apply
→ Unity reimportará con BC7/DXT comprimido

2. Cleanup de Duplicados

→ Tab "🧹 Cleanup" → Escanear Duplicados
→ Verificar cada grupo (el tool muestra qué está en uso)
→ Mantener la copia en Textures/ Unity
→ Eliminar copias Godot-UE (ya archivadas)
→ Generar reporte final HTML

3. Verificación Visual

→ Abrir cada escena y verificar materiales
→ Confirmar paredes con Metallic=0 (no deben brillar)
→ Comprobar Mat_Exit y Mat_GravityZone (emissivos)
→ Usar Memory Profiler → Textures para VRAM

4. VRAM Runtime (adicional)

Una vez aplicada la compresión BC7:
→ 512×512 BC7 = ~170 KB VRAM
→ 256×256 DXT = ~43 KB VRAM
→ Reducción VRAM estimada: ~75-80% vs. sin comprimir
→ Habilitar Texture Streaming en Quality Settings
